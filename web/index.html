Sonix Player for the TempoTec V3 Analog

Drop the vendor's v3_analog.upt here and this page builds the port's firmware image out of it. Everything happens in your browser: the file is never uploaded, and nothing is sent anywhere.

What it does is what sonix-packer/v3_analog_packer.sh does — replace the stock player with this one, install the interface and the Bluetooth userland, drop the stock libraries nothing uses any more, repack the rootfs and write the checksums the device's updater verifies. The kernel and the bootloader are carried through untouched.

Drop v3_analog.upt or — it stays on this machine

    Download v3_analog.upt

    Flashing it

    1. Copy the file to the root of the microSD card, with exactly that name.
    2. Charge the player above 30%.
    3. From this player: Settings → System → Update firmware → From SD card. From the stock firmware: its firmware-update entry. Or power on with Power + Prev held for recovery.
    4. The device says “Upgrading…”, then “Succeeded”, and reboots.

    The bootloader is never written by an update, so a flash that goes wrong can be undone with the vendor's own v3_analog.upt from the card. Going back is the same procedure with that file.

    That did not work

    The image contains the vendor's firmware: HiBy's binaries, Ingenic's kernel, the vendor bootloader. That is why it is built here, on your machine, from your own copy, and why this page does not offer one to download.
